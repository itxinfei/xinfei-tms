### 1.3 行为护栏（每阶段强制，重设计口径）

- **目标行为断言**：每个模块重构完成前，跑《27-链路测试用例》中该模块相关用例——用例断言的是**文档规格的目标行为**；跑不通的用例按重设计口径修订用例（并对齐《08》契约），**不迁就旧实现**（`D-61` ②）。
- **编译门禁**：每阶段收尾 `mvn compile` 全模块通过（JDK 21）。
- **运行门禁**：每阶段收尾该模块服务**可启动**（旧项目"跑不起来"正是本次要解决的，每个模块完成即可运行是硬验收）。
- **回退点**：每个模块重构起点打 git tag（命名 `refactor/<模块>-start`）。
- **禁止夹带**：重设计期间发现的新需求/业务口径变更，登记到《03》或对应任务卡走需求变更，**不顺手改**（`D-61` ②）。
