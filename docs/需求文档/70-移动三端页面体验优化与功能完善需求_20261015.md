### 1.3 整改原则

1. **变量优先**：页面内硬编码一律替换为 `var(--c-primary)`（或 scss `$u-primary`），禁止把新色值再硬编码一遍——《13》§1-2 红线。
2. **pages.json 例外**：pages.json 不支持 CSS 变量，直接写 `#FF0033` 字面值（uni-app 机制限制，允许）。
3. **按压色/浅底色**：原 #E15536 的 hover/选中浅底场景，替换时对应取 `--c-primary-dark: #CC0029` / `--c-primary-light: #FFE5EA`（参照《13》§2.1 语义）。
4. **同步 navbar 方案**：整改时页面若用 `u-navbar bgColor` 硬编码，替换为 `bgColor` 直接引用不可行（props 传值）——统一改为 `bgColor="var(--c-primary)"`（uview-plus 支持 CSS 值）或页面 scss 变量注入，实施时验证 H5 效果。

### 1.4 验收

- 三端全工程 `grep -i E15536` **零命中**；
- H5 构建（`pnpm -F xfwl-mobile-<端> build:h5`）后三端导航栏 / tabBar 选中 / 按钮 / 图标 / 开关全部呈心飞红，无残留橙色；
- 深浅按压态符合《13》§2.1（按压 #CC0029、浅底 #FFE5EA）。

## 二、视觉美化需求（怎么做好看）

> 设计总纲：**C 端做减法（client 极简）、作业端做效率（信息密度高、大按钮单手操作）**——《13》§5 角色化规范既定，本节为落地化需求。

### 2.1 导航栏体系统一（优先级 P1）

现状：三端大量页面用 `u-navbar bgColor="#E15536"` 红底白字 + 部分 Tab 页无 navbar，风格不一。统一为两级：

| 页面类型 | 方案 |
|---|---|
| Tab 首页（三端 home） | **品牌红渐变头**（#FF0033 → #CC0029，135deg），白字标题，头部区域下延包裹欢迎语/统计卡（沉浸式），无原生 navbar |
| 内页 | **白底黑字** `u-navbar`（`bgColor="#FFFFFF"` + 左返回 + 标题居中），去红底——大面积红只留首页与主按钮，增强质感 |
| 特殊（登录页） | 上半屏品牌红渐变 + logo-full-login.png + slogan，下半屏白色表单卡片 |

### 2.2 首页卡片化改造（P1，三端）

- **头部欢迎区**：问候语（按时段"上午好，{姓名}"）+ 今日关键数字（customer：进行中运单数；driver：今日任务/完成数；courier：今日取派量）。
- **功能宫格**：uview `u-grid` 3~4 列，图标统一 44px + `--c-primary-light` 圆角浅底容器 + 13px 文字（替代现 driver home 的裸 u-icon 行）。
- **主操作悬浮**：customer 首页悬浮"立即寄件"大按钮（uview `u-button` shape=circle，品牌红，页面底部悬浮）。
- **卡片规范**：白底、圆角 `12px`（--r-lg）、阴影 `0 2px 12px rgba(0,0,0,.04)`，页边距 16px（--s-4）——与《13》§2.4 对齐。

### 2.3 状态色体系统一（P1，横切）

三端全部状态标签（运单状态/任务状态/异常状态）统一语义映射（与《13》§2.1、管理端 §4.3.2 同源，禁止自创色）：

**待处理=warning #FF7D00 / 进行中=primary #FF0033 / 已完成=success #00B42A / 异常=error #F53F3F**

实现：抽公共 `statusTag.vue` 组件（props: status → 返回 u-tag type/文案），禁每页 if-else 写死颜色。

### 2.4 加载与空态体验（P2，横切）

- 列表页加载改 **u-skeleton 骨架屏**（首屏）+ 下拉刷新（已有页面保留 enablePullDownRefresh）；
- 空态统一 `u-empty mode="list"` + 文案"暂无数据"；错态 u-empty + 重试按钮（《13》§3.2 既定，补齐到全部列表页）。

### 2.5 tabBar 品牌化（P2）

三端 tabBar 图标与三端角色对应（司机=方向盘、快递员=包裹、客户=寄件盒），选中色 #FF0033；图标用 docs/brand 品牌资产衍生（logo-mark-transparent.png 调色），禁用 uview 默认占位图。

### 2.6 微交互统一（P2）

- 按钮按压态统一 #CC0029（u-button hover-class 全局配置）；
- 列表项按压浅底 #FFE5EA（或 rgba(255,0,51,.04)）；
- 关键操作成功反馈统一 `uni.showToast` icon=success + 品牌文案，禁 alert。

### 2.7 明确不做（YAGNI，本阶段）

- 暗色模式适配（无真实用户，dev 不做，上线前另立项）；
- 无障碍高对比、字体缩放；
- 复杂动效（Lottie/转场动画）。
